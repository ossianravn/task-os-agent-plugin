# 007 — Shared resources at the plugin root, reached by relative path

Files that several skills need live once at the core plugin's root: `references/record-format.md`, `scripts/new-id.mjs` and `templates/`. Each SKILL.md defines `<plugin>` as the folder two levels above its own and links shared files by relative path. Neither host offers a variable that works in both: Claude Code substitutes `${CLAUDE_PLUGIN_ROOT}` and `${CLAUDE_SKILL_DIR}` in skill text, while Codex substitutes nothing. Both show the agent the SKILL.md path, so relative paths work in both, including from Codex's plugin cache. The modules do not reach into the core by path, because each host installs every plugin in a folder of its own. `grill` writes records through the core's `capture` skill instead.
