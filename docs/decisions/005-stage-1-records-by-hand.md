# 005 — Stage 1 skills write records by hand

In stage 1 the skills write records as markdown themselves, with no core. Four choices keep those files compatible with the core that stage 2 adds. Ids and times come from `plugins/task-os/scripts/new-id.mjs`, a dependency-free Node script that prints UUIDv7 ids, the UTC time, and the host and session it detects: `CLAUDE_CODE_SESSION_ID` in Claude Code, and `CODEX_THREAD_ID` in Codex, which a Codex commit adds but the official docs do not list. When it finds no session, the agent mints one at its first write and reuses it. `source_refs` holds evidence shorthand (`file:`, `mail:`, `ticket:`, `url:`, `ga4:`), which SPEC.md section 5 already lets the core resolve into evidence descriptors later; an evidence record is written by hand only for a source that is not a file in the folder. Because claim records are never edited, a superseded record is found by searching for its id under `supersedes`. The managed block ships as `v0`, pointing at skills instead of the `taskos` CLI that does not exist yet; stage 2's `setup` replaces it with the `v1` block in SPEC.md section 6.
